# spam-email-detector
ML-powered spam email detector with confidence scores, prediction history, and user feedback learning.

Spam Email Detector is an intelligent email classification application that uses natural language processing (NLP) and machine learning to identify spam emails. Users can paste or upload email content, receive a Spam or Ham prediction with confidence scores, view past predictions through a history log, and optionally provide feedback to help improve the model over time. It is designed as a practical demonstration of text classification, data persistence, and continuous learning techniques.
